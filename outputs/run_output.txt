HEURISTIC NOTE
Manhattan distance h = |row-goal_row| + |col-goal_col|.
Each move changes one coordinate by exactly one, so at least h moves remain.
Every legal move costs at least 1 (crowded cells cost 4), hence h never
overestimates the remaining weighted path cost. It is an admissible lower bound.

EXPERIMENT NOTE
BFS minimizes number of moves, not weighted cost. DFS depends on neighbor order.
Greedy prioritizes only h and is not guaranteed to find a least-cost path.
A* uses f=g+h and, with this admissible heuristic and positive costs, finds
a minimum-cost route on this grid.
